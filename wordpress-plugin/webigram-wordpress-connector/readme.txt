Authenticated companion plugin for Webigram WordPress Doctor Deep Scan.

== Installation ==
1. Upload and activate the plugin.
2. Open Tools > Webigram Connector.
3. Copy the connector token.
4. Open https://webigram.ir/tools/wordpress-doctor/ and choose Deep Scan.
5. Enter the site URL and connector token.

The plugin exposes no diagnostic payload without the private token.
